# Elevated Horizon development

Application source is in `elevated-horizon/`. Run Python tests from the repository root with `python3 -m unittest discover -s elevated-horizon -p 'test_*.py' -v`.

Preserve local-only loopback binding, Host checks and CSRF protection. Do not expose the server publicly. Do not commit runtime SQLite databases, JSON backups, customer records, banking or identity documents. Use fictitious test data only.

Quotes remain drafts and must never be silently treated as invoices or sent. Flight checks are human documentation, never automated flight authorization. Preserve version snapshots and payment reconciliation gates. Do not infer that a payment was received from an order or screenshot.
